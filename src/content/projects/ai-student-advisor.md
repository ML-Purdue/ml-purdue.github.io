This project aims to create an LLM chatbot advisor based on official Purdue
information.

## Objectives

1. Train a valid local LLM that can answer basic user queries without relying on
   RAG, in a format aligned with human preferences
2. Optimize RAG pipeline speed, and lower RAG costs where possible
3. Optimize the web UI and make the site more professional
4. Train a graph tool for course planning that picks the shortest path to
   graduation given a student's current classes
